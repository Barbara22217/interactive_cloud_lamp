# Interactive Cloud Lamp
Interactive Arduino cloud lamp with programmable LED lighting: https://youtube.com/shorts/52P8XduLB4Y?feature=share

This project is an interactive ambient lamp built with an Arduino Uno and an addressable LED strip. The goal was to combine simple electronics with a physical object to create a lighting piece that responds to user interaction.
![Cloud Lamp](images/final_lamp.jpg)

The lamp can be turned on and off, change colors, adjust brightness, and switch to a dynamic party mode using buttons and a potentiometer. A touch sensor also activates a slow “breathing” light effect that gives the cloud a soft, atmospheric glow.

The idea behind the project was to see how a basic electronics setup could be turned into a more playful and atmospheric lighting object.
